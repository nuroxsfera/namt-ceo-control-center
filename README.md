# NAMT CEO Control Center

**Interactive AI-powered holding company operating system**  
MVP 1.0 | NAMT Group International

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Recharts
- Lucide Icons
- Zustand (state)
- React Router

## Features (MVP)

- Dashboard with key metrics & charts
- AI Employees management
- Tasks (Kanban + Table)
- Finance center (with DEMO marking)
- Clients CRM
- Agency, Media, Labs sections
- Reports
- CEO Decisions center
- Full RU / EN localization
- LocalStorage persistence
- Responsive design

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Design Direction

**Hybrid Authority**  
Dark sidebar + light content area.  
Primary accent: Teal (namt-600).  
Premium, modern, CEO-grade operating system feel.
